# Contributing to XBL-Account-Creator

##### Thank you for your interesting in contributing, this document explains how you can improve the project.

>[!IMPORTANT]
>By Contributing to **XBL-Account-Creator**, you agree to follow out [Code Of Conduct](COC.md).

## Reporting Bugs
- Check the [issues page](../../issues) to check for bugs that have already been reported first.
- If the bug you wish to report has not been reported, open a new issues with:
	- A clear Title and Description explaining the bug.
	- Steps to reproduce the bug.
	- Expected behavior, vs actual behavior.
	- Any logs, screenshots, or error messages.

## Suggesting Features
- Open a new issue labeled **enhancements**.
- Explain why the feature would be useful and how it would be used
- Explain what exactly it's supposed to do

### Setting up the project locally
1. Fork the repository:
2. Clone your fork:
```bash
git clone git@github.com:username/XBL-Account-Creator.git
```
